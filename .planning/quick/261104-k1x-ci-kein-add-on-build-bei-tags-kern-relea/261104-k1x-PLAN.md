# Quick 261104-k1x: CI-Nachtrag Kern-Release

**Ziel:** Die Plattform pinnt eine bytegleiche Datei mit Prüfsumme statt des GitHub-Archivs (Archive sind nicht garantiert bytestabil); der Add-On-Build läuft nicht mehr bei Tags.

## Aufgaben
1. `build-elm-sab-tapir.yml`: `push.branches: ['**']` — Tags lösen den Build nicht mehr aus (Release schreibt ohnehin nur `main`).
2. `core-release.yml`: Wheel + sdist bauen (`python -m build core`), beide ans Release hängen; Release-Notiz nennt die pip-Zeile mit `#sha256=` der Wheel-Datei (pip prüft den Fragment-Hash, ohne den Hash-Zwang für alle Pakete einzuschalten).
3. Kern 0.2.1 (`pyproject.toml`, `__init__.py`), README-Installationszeile auf die Wheel-Datei.

## Prüfung
- YAML parsen, Kern-Tests grün, nach Tag `core-v0.2.1`: Release hat `.whl` + `.tar.gz`, Installation per URL+`#sha256` klappt, falscher Hash wird abgelehnt.
